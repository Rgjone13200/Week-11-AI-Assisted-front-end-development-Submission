# Week-11-AI-Assisted-front-end-development-Submission
EcoRise is a nonprofit website redesign project focused on promoting sustainability, increasing community engagement, and making it easier for users to explore programs, events, resources, and donation opportunities. The site was designed with a clean, accessible layout and a mission-driven visual style to inspire eco-conscious changemakers while improving the overall user experience. An AI assistant was also used during the design and development process to help generate ideas, refine content, organize structure, and support the creation of wireframes, copy, and layout decisions.
